## 一、你报的问题，其实是三个 bug 叠在一起

### ① 扫完码永远「未登录」：cookie 造出来了，但没写进盘

扫码换凭证那一步**成功了**（服务端回 `code=0`），票据也拼出来了，
但代码把它**返回给调用方之后就没了** —— 没有任何一行把它写进本地存储。

而调用方（我写的那个浮层）当时的注释理直气壮地写着
「cookie 与续期凭证都已经落盘，这里不再保存」—— 那句话是错的。两边都以为对方会写。

所以你手机上的现场长这样：

| 落盘的东西 | 状态 |
|---|---|
| `qq_refresh_credential`（续期凭证） | ✅ 在 |
| `qq_cookie`（登录态本身） | ❌ **不在** |

⇒ App 判定「未登录」，界面永远让你重新登录，而日志里一切正常。

### ② 明明能续期，却被判成「不会自动续期」

我们原来要求「必须拿到 `refreshKey` 或 `refreshToken` 才允许续期」。
而你那次扫码，服务端把这几个键**都给了、值都是空的**（字段骨架有 35 个，票据只有一把）
⇒ 判成「不可续期」⇒ App 根本不会去续，界面上还写着「到期不会自动续期」。

**这个判据是错的。** 我用你手上那份真实凭证实测了一次续期：
**只带 `musicid` + `musickey` + `openid`，就换回了一张新票**（服务端回 `code=0`）。
也就是说：能续期的真正条件是「有身份 + 有上一张票」，而不是「服务端有没有大发慈悲给你 refreshKey」。

### ③ 续期请求每次都被服务端拒（最隐蔽的一个）

就算前面两条都修好，续期**仍然会失败** —— 因为它借用了「登录」那条通道，
而那条通道会往请求里塞一个 `tmeLoginMethod=3`，那是**手机验证码登录**才该有的字段。

同一份凭证、同一个请求体，只改这一个字段的实测：

| 请求里带什么 | 服务端结果 |
|---|---|
| 只带 `tmeLoginType` | **`code = 0` + 一张新票** ✅ |
| 多带 `tmeLoginMethod = 3` | `code = 1000`，换不出票 ❌ |

后果是「明明登录着，每到第 3 天还是掉」—— **你最初报的那个问题原样复发**。
这个 bug 比原来那个更难查：票据是好的、网络是通的，只有一个不该出现的字段在那儿。

## 二、这次是真机验证过的（上一版这里写的是「未验证」）

我把设备上落盘凭证的签发时间手工往前推了 7 天（等于票据已过期），然后冷启动 App，
**让生产代码自己去续期**：

```
I/QqTokenRefresher: qm 登录态已静默续期 newCredential={musicid=set loginType=1
    musickey=len163 keyCreatedAt=1791483130 keyExpiresIn=259200 refreshable=true}
```

落盘读回：签发时间 `1790877630 → 1791483130` —— **换到了一张新签发的票**。

v3.4.9 的发布说明里我把「续期的成功路径没有真机样本」列为未验证项；
现在这一格有证据了。

## 三、你手上的操作

1. **装这一版**（覆盖安装 v3.4.9，数据保留）；
2. 如果 v3.4.9 里你还没登录上：用**「QQ 音乐 App 扫码」**再扫一次即可（这次会真的登录上）；
3. 之后**不需要再管它** —— 票据寿命 3 天，剩不到 12 小时时 App 会在冷启动时自己换新票。

**一个如实的说明**：你账号走的是微信绑定（`loginType = 1`，票据前缀 `W_X_`），
这类账号的票据寿命实测是 **3 天**（`keyExpiresIn = 259200`），比手机号那条路短。
所以没修好之前你会**每 3 天掉一次**（不是你感觉的「一周」，那大概是更早以前那条路的现象）。
修好之后这件事由 App 自己处理。

## 四、这一版的三个 bug 是怎么被发现的（值得记一笔）

它们有一个共同形状：**每一个都只在真机上、只在完整的成功路径上才会露出来。**

- 我在发布前写的 27 条报文级单测全绿 —— 它们测的是「MQTT 报文对不对」；
- 打真实服务端的 3 条探针也全绿 —— 它们测到「握手 + 订阅成功」为止；
- 而 ① 在**落盘**那一层、② 在**判定**那一层、③ 在**另一个通道的某个字段**上，
  三层都在「协议通了」之后。

也就是说：**「协议通了」不等于「功能通了」**。这一点我上一版写在未验证项里，
但低估了它的范围 —— 我以为只有「扫码确认那三步」没验，实际上从确认到落盘到续期，
中间还有三段路只有真机能走。你这次试用一次就全撞出来了。
