# Arris v3.7.8-gpl

versionCode **94**。本版**只做修复**，没有新功能。全部改动来自 2026-10-27 的审查清单
（[`docs/reviews/2026-10-27-BUG_SUMMARY.md`](../../reviews/2026-10-27-BUG_SUMMARY.md)），
逐项修复记录见 [`BUG_FIX_2026-10-27.md`](BUG_FIX_2026-10-27.md)。

## 一、数据安全：删除意图、落盘提交与取消语义

- **在途同步不再复活已删歌单**：本地歌单新增修订号，同步提交前复核「期间有没有人动过」；
  删除或增删曲目都推进修订号，旧同步一律作废（S2）。
- **统计清空不再被旧快照写回**：代次校验与落盘提交进同一把锁，清空的删除也带自己的代次（S4）。
- **本地歌单写盘失败不再谎报成功**：写盘结果一路上传到界面，失败保留对话框与重试入口（S5）。
- **队列读写不再把协程取消当故障**：取消原样传播，读失败不删盘，写盘按代次串行（S15）。
- **退出播放器不再清掉播放模式**：只清当前播放状态，保留模式/队列/续播（S16）。

## 二、会话归属与写入顺序

- **B 站扫码登录收尾绑定登录代次**：迟到的 `nav` 既不能清掉新登录，也不能把资料写成上一个账号（S6）。
- **收藏/取消按曲目串行 + 最新意图**：连点时云端最终状态等于用户最后一次操作（S17）。
- **异步写操作钉住原会话**：切账号后旧操作作废，不再用新账号凭据兜底（S18）。
- **局域网配对加认证**：协议升级到 `NCRUSTPAIR2`，二维码携带配对密钥、应答带 HMAC 证明、
  密钥掺入该密钥；二维码没有密钥时**拒绝回传**（不静默回退到明文派生）（S19）。

## 三、音源载荷与写接口

- **车机路径补回 QQ 取链载荷**：按曲目身份从本地歌单/收藏回查 `songmid`，补不到仍判不可解析、不换源（S20）。
- **旧收藏的身份与载荷对齐**：解码时以 `trackKey` 为准回填/纠正音源（S21）。
- **网易歌单写接口拒绝跨源 id**：QQ/B 站合成 id 在写出口被拦下（S22）。

## 四、缓存、统计、搜索、下载、提示

- **QQ 部分/降级歌单不再算完整同步成功**：不完整只合并、不更新同步时间戳（S1）。
- **QQ 按账号清缓存按 owner 段匹配**：四种 key 形状都正确，不再误删其它账号（S3）。
- **缓存枚举失败不再裁剪离线索引**（S8）。
- **统计按「在播身份」记账**：慢网下不会把上一首的时长记到新请求的歌上（S7）。
- **聚合搜索按来源重试失败页**：某源第 2 页失败不会被跳过，来源计数按唯一结果计算（S9）。
- **下载隔离 part 文件**：取消的旧任务不能截断已完成的新包；响应 ETag 在写字节前落盘，
  缺验证器的 URL 回退身份放弃拼接、整包重下（S10、S11）。
- **清首页缓存同时失效新鲜度**；空列表快照=成功清空；首页个性化缓存绑定账号（S12、S13、S14）。
- **车机试听时长单位统一为秒**；车机按当前网络选择音质档位（F1、F2）。
- **加入歌单失败不再弹成功提示**（F3）。

## 五、跨源匹配策略（C1）

版本判定从「有没有版本标记」改为**比较版本种类集合**：原版 / 伴奏 / Live / Remix / 重制 / 豪华版
互相之间不再合并，避免「播放全部」里被伴奏顶替或丢掉一个版本。
匹配缓存算法版本推进到 **2**，旧结论整体失效。
