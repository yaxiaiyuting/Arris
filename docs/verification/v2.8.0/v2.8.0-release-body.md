## 1. 这个版本做了什么

两件事：**波形效果分级**（P1-A）与**设置界面二级菜单重构**（P1-B）。

### 1.1 波形效果分级：简洁 / 精致 / 炫技

播放器的音频可视化（大屏幕模式左栏 / 平板横屏）现在有三档，设置里可选：

| 档位 | 内容 | 默认给谁 |
|---|---|---|
| **简洁** | 圆角柱 + 柱间距 + **峰值保持** + 缓动衰减 | **低端设备默认**：低内存机型 / 3 GB 级 / Android 7.x |
| **精致** | 简洁档 + **渐变流动** + **柱顶光点** + **呼吸** | 其余设备默认 |
| **炫技** | 精致档 + **冲击波** + **粒子** + **3D 透视**（另有「炫技效果」总开关，默认关） | 用户手动选 |

同一页还有一条如实说明：**波形亮度表示的是「时间新旧」，不是频谱** —— 本版没有频域数据，
不区分低/中/高频，所以不会画出任何会让你误以为是频谱的东西。

顺带修掉三处底层问题（都有单测）：

1. **v2.2.1 的隔离只做了一半**：可视化 tee 把 RMS 计算包进了异常隔离，但把结果交给 UI 的那一行留在
   隔离之外 —— 那是**唯一还能把播放打挂**的路径（media3 对 sink 回调不兜异常）。现在「计算 + 回调」
   在同一个隔离边界里，失败只丢一根柱，绝不影响播放。
2. **关掉可视化不再是「假关」**：旧写法下用户关掉开关后，音频线程仍会为一份没人看的 RMS 遍历整块 PCM。
   现在开关判断在计算之前，且音频线程不读磁盘。
3. 音频线程上每个缓冲的 2 次堆分配被消掉（改用绝对下标读字节，数值与旧实现逐样本对齐）。

**性能兜底（有界）**：帧时间持续超标时会**自动下调一档**（60 帧窗口里 ≥24 帧超过 16.67 ms），
每个进程最多降一次、降完写回档位。S6（2015 年机型）实测该降级真的会触发 —— 因为它的 P50 本来就在
20 ms 左右，所以在这类设备上你选「精致/炫技」会被自动降回「简洁」。这是刻意行为（性能不达标就降级），
但如果你希望「我选了就别动」，请在 issue 里说。

### 1.2 设置界面改成「一级分组卡片 + 二级详情页」

一级页现在是 7 张卡片（图标 + 标题 + 副标题 + 箭头，直角、跟随封面色）：

| 分组 | 里面有什么 |
|---|---|
| 账号与登录 | 网易云账号、QQ 音乐账号（含扫码/手机号登录） |
| 通用 | 显示语言、自动旋转、音乐人推荐、后台运行等 |
| 外观与动效 | 主题模式 / 主题色 / 主题色来源、页面切换动效、自定义背景 |
| 播放与音质 | WLAN / 移动数据音质、无缝播放、禁止熄屏、**音频可视化 + 波形档位** |
| 歌词 | 翻译、逐字动画模式、渐变质量、字号、媒体面板歌词、AMLL TTML、TTML 优先、音译、动态字号 |
| 存储与缓存 | 离线缓存上限与「离线缓存管理」、清缓存 |
| 关于 | 版本信息、项目主页 |

**行为不变**是硬要求，并且是机械校验的：每个设置项的读写路径、key、默认值都与迁移前一致，
单测里有一条**双向 key 等值**断言（少一项会红，多塞一个无关功能项也会红）。
依赖关系照旧门控（关掉 TTML，「TTML 优先」整行不出现；渐变质量在非「渐变扫过」模式下置灰并说明原因）。

## 3. 已知问题与不粉饰的结论

- **S6 这类老机上，新波形比 v2.6.2 的旧波形更贵**（P50 +5…8 ms、P90 +2…6 ms、P99 +11…22 ms），
  帧产出量基本不变、没有卡死级联，但确实更吃性能。低端机默认走「简洁」档 + 自动降级是缓解手段。
- **炫技档的三项（冲击波/粒子/3D 透视）只在「炫技」档 + 打开「炫技效果」后生效**；
  其中 3D 透视是合成开销最高的一项。
- **拖拽交互没有实现**：设置里那一项叫「**点按**切换着色」，就是一键在「渐变流动」与「按时序着色」
  之间切；真拖拽手势与播放器手势的冲突需要真机 A/B，本版没做（设置项说明里也这么写）。
- **平板 WGR-W09 只验证了设置界面与迁移，没做波形验证**（该机无 root，装新签名包必须卸载重装）。
- **PCL110 只测了默认档（精致）的帧时间**，简洁/炫技档未测。
- **音频线程侧开销未单独测量**（`handleBuffer` 回调率、RMS 逐样本成本）。
- 设置里 `offline_cache_mb` 现在有**两个入口**（存储页下拉 + 离线缓存管理弹窗内的选择器），
  两处读写同一个存储、弹窗关闭后页面会重读一次；这是「每个设置项都必须能从二级页到达」的副产物。

1. **完全卸载旧版本**（必须；签名不同，覆盖安装会失败）；

3. 重新登录网易云 / QQ 音乐，重新按需设置缓存上限等选项。
