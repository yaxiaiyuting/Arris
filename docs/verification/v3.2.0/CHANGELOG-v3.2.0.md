# Ncrust v3.2.0-gpl 更新说明（用户可读）

> 版本：`3.2.0-gpl` ｜ `versionCode 55`
> 构建产物：`Ncrust-v3.2.0-gpl-release.apk`

---

## 修好了什么

### 1. QQ 音乐 VIP 歌曲不再被说成「没有版权」，也不会被自动跳过

旧版会在取不到播放链接时一律提示「此源无版权，可切另一源」，然后**自动跳到下一首**。
问题是那句话在多数情况下是**假的**：实测同一首 VIP 歌在未登录时服务端回的是
「需要登录 / 需要会员」（`104003`），与版权毫无关系；网络抖动也会走到同一句提示。

现在按服务端真正给的原因分别处理：

| 服务端说的 | 你会看到 | 会不会跳歌 |
|---|---|---|
| 需要登录 / 需要会员 | 「需要登录 QQ 音乐…」/「需要会员权益，若已开通请重新登录刷新凭证」 | **不跳** |
| 需要单独购买 | 「需要单独购买后才能播放」 | **不跳** |
| 登录过期 | 「登录状态已过期，请重新登录」 | **不跳** |
| 网络异常 | 自动重试（每首最多 2 次），仍失败才提示 | **不跳** |
| 版权方确实声明无版权 | 「该音源暂无版权，可换个音源试试」 | **不跳**（换源由你决定） |

只有「这首歌在这个音源上根本不存在」（比如队列里的老数据缺了必要标识）才会跳过。

### 2. B站能搜到歌了；「只搜 B站」不再卡死

- **搜不到**：B站的网络请求之前跑在**界面线程**上，被系统当场拒绝（毫秒级），
  而那个错误被一个兜底捕获悄悄吃掉了 —— 于是永远是「B站 0 首」，还什么都不报。
  现在所有 B站请求都在后台线程上跑。
- **卡死**：筛选档（「双源 / 只看网易云 / 只看 QQ 音乐 / 只看 B站」）之前画在
  结果列表**里面**，而你切到「只看 B站」后如果没有 B站结果，整条列表连同筛选档
  一起被换成了空白 —— 于是没有路径切回去。现在筛选档常驻在列表外面。
- 同时补上了结果区的加载提示与下拉刷新（用的是仓库里已有的组件）。

### 3. 歌词全屏时左上角的迷你封面不再错位

它之前比它应该在的那一行**低了 12dp**（真机实测 45 像素），而且紧贴屏幕左边缘。
原因是封面按收起态托盘的（80dp）中心摆，而全屏顶栏只有 56dp。已按设计规范对齐。

### 4. 选「简洁」档之后，界面真的不再抖了

两处漏网：封面的逐帧浮动用的是「封面浮起阴影」那个开关（在简洁档恒为开），
背景呼吸在简洁档也一直开着。现在**简洁档是真正的静态档**。
（顺带修了一处会被这次收窄打坏的地方：简洁档的波形之前是靠「背景呼吸」的帧循环
推进的，只关呼吸会让波形冻住 —— 已解耦。）

## 新增了什么

### 5. 界面律动的独立开关

设置 →「外观与动效」新增：

- **界面律动（随节拍）** —— 总闸
- **封面浮动**（最多 2dp）
- **歌词律动**（最多 3%）
- **控制条脉冲**（最多 2%）

「背景呼吸」沿用已有的那个开关。**关掉总闸只掐这四类「跟着音乐一起动」的效果**，
冲击波、光晕、粒子一概不受影响。四项默认全开（与升级前一致）。

### 6. B站扫码登录（可选）

设置 →「账号与登录」新增 B站账号块，用哔哩哔哩客户端扫码即可。

- 凭据**只保存在本机**，本应用**只读取**，不投币、不收藏、不点赞；
- 音源开关与登录态**相互独立**，登录不会自动打开 B站音源；
- ⚠️ **如实说明**：登录后音质是否有提升**本版没有验证**（缺少大会员账号做对照），
  界面上也这么写。匿名下的上限是 320K。

## 本版没有验证的事（与上面同等重要）

- **QQ VIP 歌曲「被误判」这个现象本身没能在真机上稳定复现**：用有效的 VIP 账号
  12 首歌 × 8 个音质档 = 96 次取链，一次都没出现取不到链接。
  修复依据是源码链路上的四条事实（判定逻辑根本不存在、失败原因被丢弃、
  提示文案断言了客户端没证据的结论、失败与播放失败共用会跳歌的那条路径），
  **触发条件是概率的** —— 比如票据失效一次就会命中。
- **迷你封面修复后的真机截图没有采集**（设备上装的是上一版；调试包签名不同，
  强行覆盖会清掉设备上已登录的账号，代价不对等）。
- 前几版的老问题仍在：B站曲目的**实际播放**（字节取流）未验证；B站歌词不进缓存
  （断网无词）；真 FFT 仍然没做。
