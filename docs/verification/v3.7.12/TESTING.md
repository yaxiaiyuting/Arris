# v3.7.12-gpl 双语媒体歌词测试包

版本 3.7.12-gpl / versionCode 98。代码分支 feat/bilingual-media-lyrics；以 0fd05bf 的既有 3.7.11 工作区快照为基线（31 文件，保持原工作树不动）。这批既有歌词分享/资料等变更包含在测试包里，不算本轮新开发或已验证的全部产品功能。

## 使用

1. 覆盖安装 release 签名测试 APK。
2. 设置 → 歌词 → 打开「媒体面板显示歌词」（已有偏好保留，不强行覆盖关闭状态）。
3. 「双语双层歌词」默认开；「媒体歌词主行」默认「原文在上」，可切换「译文在上」。
4. 播放有译文的外语歌曲，检查通知/锁屏媒体面板和系统实况窗。无译文的当前句应只显示原文；无歌词时显示歌名与歌手。
5. 暂停时切换主行、拖动进度、切到无译文歌曲、再切回有译文歌曲，检查两行归属与恢复。

## 验证边界

复用已取得的翻译轨，不增加在线翻译或其它网络请求；应用内原有歌词翻译开关与媒体双语偏好独立。系统模板决定字号、截断及胶囊收起态能显示几行，需用户设备确认。未作本轮真机/模拟器测试，未打开可见浏览器或自动播放；源码审查任务继续暂停。最终 JVM、Lint、APK 版本/签名与 SHA-256 证据见 RELEASE_VERIFICATION.md 与 verification.json。
