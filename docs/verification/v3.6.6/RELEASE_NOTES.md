修复生日庆祝结束按钮过低，以及波形历史突然消失的问题。

- 生日结束的「继续听歌 / 再看一次」现在直接跟随祝福文字排版；横竖屏、小屏会一起测量文字和按钮高度，按钮不再独立贴住屏幕底部。保留点按吹灭、真实吹气与重播许愿门控。
- 重新缓冲时冻结已测波形和滚动时钟，恢复后重新锚定；不再把缓冲误当成暂停衰减。
- 界面长卡顿或数据积压时只丢弃过时的待处理样本，保留屏幕上的波形历史，再按正常节拍接入新列。真实缺样仍留空，历史正常从左侧滚出；没有复制峰值来填补缺样。

验证：3001 项 JVM 测试通过；浏览器检查 8 种横竖屏视口（320×480 至 1280×720），退出、重播和许愿门控均通过；Android API 33 WebView 检查结束按钮位置及退出回调。正式包使用原签名，可覆盖安装。

本轮没有操作或测试实体手机。WebView 的设备性能差异、真机横屏长时间播放仍需用户安装后确认。映射文件与校验和随包附上，Release 保持草稿。
