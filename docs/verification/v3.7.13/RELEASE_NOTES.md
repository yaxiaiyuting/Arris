# Arris 3.7.13-gpl 弱网与播放操作修复测试包

本地测试交付，versionCode 100。保留正式3.7.11/99和旧双语3.7.12/98，不覆盖既有APK、标签或历史证据。

## 网络与播放恢复

- 新选曲先更新所选歌曲信息，停止旧媒体项，取链失败仍保留所选曲；下一次点击播放会重新解析它，不再对上一首的空/失败媒体项反复调用play。
- 明确断网且无完整可播缓存时，直接进入网络等待，不跑远程取链阶梯；缓存可播则直接使用。联网取链失败或超时后仍尝试完整离线缓存。
- 新的播放/切歌操作立即撤销旧取链、重试与预载归属。网易、QQ与B站相关JSON请求的取消覆盖响应头与响应体读取；已经拿到可播URL后的网易音质能力补查最多等待1.2秒。
- 监听系统默认网络变化，将Wi-Fi、蜂窝、VPN底层/验证状态的变化合并500ms。只有最后未被用户暂停/停止、仍在取链/网络等待/缓冲的请求可恢复；健康播放不会仅因切网重启。
- 缓冲持续12秒会按既有次数门重新解析当前曲目的URL；新网络、新曲或明确用户重试重置重试计时。网络恢复不会抢播旧选曲，也不会覆盖暂停意图。
- 应用播放键和Media3执行入口共用未就绪媒体项恢复逻辑；手动暂停后续播会重新绑定当前播放代次，之后仍能处理切网。

## 连续切歌与封面

- 上/下一首每次点击推进队列游标，停手220ms后只提交最后一个播放目标；中间项不取链、不逐个触发封面过渡。直接选择歌曲会撤销尚未提交的连点目标。
- 竖屏与横屏封面改为可用边长的88%，给标题、光影和可视化留白。竖屏标题未完成首帧测量时先预留高度，字体/密度变化会更新封面几何，继续复用同一封面动画节点。

## 验证边界

本轮无真机、模拟器或可见浏览器测试，无自动播放，不接触真实账号或云端写入。网络回归均用本地拦截夹具，状态机/队列合并/几何回归为JVM执行；Android系统网络回调、Compose动态布局和ROM媒体控件的实际效果需要后续设备验收。具体检查结果、源码SHA、产物与校验值见RELEASE_VERIFICATION.md。未推送代码、创建标签或上传GitHub。
