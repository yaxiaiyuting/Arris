# 探针 §2.3 主导频段定义方案 —— 真实音乐实测

数据源：生产类 `AudioFeatureExtractor`（一行未改）逐缓冲跑 5 首 320kbps 完整歌曲的 PCM。
缓冲粒度取 **4410 帧 = 100ms**（S6 实测值，见 `docs/verification/v3.0.0/probe/EVIDENCE.md`），
另跑 1024 帧（约 23ms）做敏感度对照。**切换频率 = 颜色改变次数 ÷ 时长（次/秒）**；
「闪断」定义为一次驻留 < 100ms 的切换。

## a 与 b 的等价性

实测：方案 a（瞬时最大）与方案 b（占比最高）在 5 首曲目上的切换次数、闪断次数**完全相同**。
原因是数学上的恒等：`argmax(low, mid, high)` 与 `argmax(low/S, mid/S, high/S)`（`S = low+mid+high`）
是同一个决策 —— 同一个正分母不改变大小顺序。**两者不是两个可选方案，是同一个方案。**
