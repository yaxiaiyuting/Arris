# 探针 §2.4 颜色切换方式实测（生产 `BandDominance`，60fps 判定 / 11Hz 输入）

主题色取预设·云杉 `#1DB954`（深色主题），三角色 = `BandColorRoles.paletteFor`。

「每帧最大色差」= 相邻两帧混合色的 CAM16-UCS ΔE 的最大值 —— 它就是「闪不闪」的数值形式：
硬切会把一次切换的全部色差压进**一帧**，有过渡则摊到 N 帧。
