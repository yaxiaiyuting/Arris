# 探针 §2.4 主导频段三色（HCT 三角色）可区分性实测

判据：任意两色 **CAM16-UCS ΔE ≥ 5**（必需）/ **≥ 10**（理想）；每色对它所在主题底色的 **WCAG 对比度 ≥ 3.0**。

实现：仓库自带的 `ui/theme/color/`（`Hct` / `TonalPalette` / `Cam16`，material-color-utilities 派生）。

primary 固定 = **主题色本身**（保住既有识别度）；secondary / tertiary 由主题色的 HCT hue 旋转 + 指定彩度得到，**tone 与主题色相同**（只换色相与彩度，不换亮度）。
