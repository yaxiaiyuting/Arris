# 探针 §2.3 主导频段定义方案（探针结论）

> 探针产出：本文件是**结论**；原始实测数据在 [`probe/dominant-band-measurements.md`](probe/dominant-band-measurements.md)
> 与 [`probe/dominant-band-timeseries.csv`](probe/dominant-band-timeseries.csv)（逐缓冲时间序列）。
> 测量发生在**任何生产代码改动之前**；测的是生产类 `AudioFeatureExtractor`（当时一行未改）。

### 2.1 方案 a 与 b 是**同一个方案**（数学恒等，已实测）

`argmax(low, mid, high)` 与 `argmax(low/S, mid/S, high/S)`（`S = low+mid+high`）是同一个决策 ——
同一个正分母不改变大小顺序。实测 5 首曲目的切换次数与闪断次数**逐首完全相同**。
⇒ 任务书列的 a/b 两个候选其实是**一条**，"占比最高"作为独立方案不成立。

### 2.2 缓冲粒度敏感度（这条决定了能不能只按 S6 的 11 Hz 选型）

| 方案 | 100ms 缓冲 | 23ms 缓冲（现代设备可能更细） |
|---|---|---|
| a. 瞬时最大 | 1.258 次/秒 | **4.260 次/秒** |
| c. 平滑 300ms | 0.308 | 0.422 |
| **d. 平滑 300ms + 滞回 20%** | **0.118** | **0.130** |

⇒ 方案 a 在更细的缓冲下**穿越 3 次/秒的不合格线**（4.26），凡是只按 11 Hz 选型、
不加平滑与滞回的实现，在现代设备上会明显更闪。滞回方案对缓冲粒度**几乎不敏感**（0.118 → 0.130）。

### 2.3 逐曲最差情况（4410 帧 = 100ms）

| 类型 | a | c(300ms) | **d(300ms+20%+闸门)** |
|---|---|---|---|
| 电子 | 2.009 | 0.621 | **0.169** |
| 古典 | 1.027 | 0.356 | 0.169 |
| 人声 | 0.898 | 0.372 | 0.157 |
| 说唱 | 1.867 | 0.146 | 0.059 |
| 纯音乐 | 0.013 | 0.020 | 0.000 |

⇒ 最差曲目是**电子乐**（a 方案 2.0 次/秒、d 方案 0.169 次/秒），仍比不合格线低一个数量级。

## 3. 结论（选型）

| 项 | 选定值 | 依据 |
|---|---|---|
| 平滑 | **EMA，τ = 300ms** | 150ms 只降到 0.540；600ms 更稳但跟不上主歌→副歌的段落变化。300ms 已够 |
| 滞回阈值 | **20%** | 5%→0.205、10%→0.161、15%→0.133、20%→0.118、30%→0.085、50%→0.054。20% 之后收益明显变平，而颜色会越来越"懒得动" |
| 静音闸门 | **三频带平滑值之和 < 0.06 时保持当前频段** | 安静段里 argmax 只是在挑底噪。实测最短驻留 100ms → **300ms**、切换频率 0.118 → 0.103 |
| 最短驻留保护 | **不做** | 实测与「闸门」完全等价（126 次 vs 126 次）⇒ 零收益的复杂度，不加 |
| 判定时机 | **按帧（60/30fps）推进 EMA，输入仍是 11 Hz 的缓冲值** | 输入分段恒定时 `k = 1 − exp(−dt/τ)` 与连续解逐点相等，帧率不改变时间常数（生产类 `BandDominance` 的 KDoc 有推导） |

**最终：切换频率 0.103 次/秒（5 首平均）、最差曲目 0.169 次/秒、零闪断、最短驻留 300ms** ——
比"不合格线"（3 次/秒）低约 30 倍。

## 4. 对 v3.2.2 的约束（由本探针直接推出）

1. **不得用裸 argmax 上色**（铁律 30）：必须平滑 + 滞回 + 短过渡，三级缺一不可。
2. **频带占比决定了颜色映射**：中频占 2/3 的时间（低 0.33 / 中 0.66 / 高 0.00）⇒
   **中频必须映射到主题色本身**，否则波形会长期偏离主题识别度（见 `BandColorRoles` 的 KDoc）。
3. **判定必须在 UI 侧**（读已发布的 volatile 标量），不得在音频线程新增任何计算（铁律 29）。
4. **特征不可用必须退回单色**：降级路径的 `mix = 0.0` 会把「测不到」画成「全是低频」，
   主导频段着色不能继承这个缺口。
