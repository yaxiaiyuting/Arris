# 探针 §2.5 曲线平滑算法（探针结论）

> 原始实测数据：[`probe/curve-smoothing-measurements.md`](probe/curve-smoothing-measurements.md)。
> 测量发生在生产绘制代码改动之前；测的是**生产** `AudioFeatureExtractor` +
> **生产** `WaveformRing` 产出的真实柱高序列（测试：`V322CurveProbe.kt`）。

## 1. 方法

| 项 | 内容 |
|---|---|
| 输入 | 5 首完整歌曲 → 生产提取器（4410 帧 = 100ms 缓冲）→ 生产环形缓冲（28 柱 / 起音 22ms / 回落 130ms） |
| 采样 | 按 16ms 帧推进、每 4 帧取一帧统计，共 **19055 帧**；每帧 27 段 × 16 采样点 = **8 250 815 个采样点** |
| 被插值的量 | **振幅域**（`sqrt(柱值)`），即渲染层真正映射成像素高的那个量 |
| 判据 | 过冲 = `max(曲线) − max(数据)`；下冲 = `min(数据) − min(曲线)`；**负高度 = 采样点 < 0**（铁律 31） |

## 2. 四种算法实测

| 算法 | 出现越界的帧 | 最大过冲 | 最大下冲 | **负高度采样点** | 出现负高度的帧 |
|---|---|---|---|---|---|
| Catmull-Rom（均匀参数化） | 14112 / 19055（74%） | 0.02273 | 0.01701 | **4066** | 224 |
| 单调三次 · 朴素（中心差分 + 圆条件） | 13277 / 19055（70%） | 0.01309 | 0.01107 | 0 | 0 |
| **单调三次 · PCHIP（保号切线 + 圆条件）** | **0 / 19055** | **0.00000** | **0.00000** | **0** | **0** |
| 贝塞尔 + 控制点限幅 | 0 / 19055 | 0.00000 | 0.00000 | 0 | 0 |

### 2.1 关键发现：Catmull-Rom **真的会画出负高度**

4066 个采样点为负、224 帧命中。在镜像丝带的几何里，负高度不是"画到画布外"，
而是**曲线穿进自己的镜像里** —— 视觉上是波形"翻了一下"。这不是理论风险，
是 5 首真实歌曲里 1.2% 的帧。

### 2.2 关键发现：**只抄圆条件是不够的**

「中心差分 + 圆条件限幅」是照着 Fritsch–Carlson 最容易写出的形状，
实测它**仍会在 70% 的帧里过冲 1.3%**：当相邻两段斜率反号且前一段更陡时，
中心差分给出的切线会与当前段斜率**反号**，此时 `|m| ≤ 3|Δ|` 不再把控制点关在区间里。
必须**同时**加保号条件（`m_i · Δ_i ≤ 0 ⇒ m_i = 0`）与端点的同向夹取。

## 3. 结论（选型）

**选「单调三次 · PCHIP」**，实现落在 `ui/player/waveform/WaveformCurve.kt`（纯逻辑，JVM 直测）：

| 项 | 取值 |
|---|---|
| 内部点切线 | 加权调和平均（PCHIP 原式） |
| 端点切线 | 单侧差分 + 同向夹取（`|d1| > |d0| ⇒ 3·d0`，否则 `d0`） |
| 保号 | `m_i · Δ_i ≤ 0 ⇒ m_i = 0` |
| 圆条件 | `a² + b² > 9 ⇒ 等比缩到 3/√s` |
| 控制点 | 三次贝塞尔，x 固定在 `1/3`、`2/3` 处 ⇒ **时间轴单调，x 不会倒退** |
| 过冲/负高度 | **0**（实测 19055 帧 8.25M 采样点） |

**为什么不用同样 0 过冲的「控制点限幅」**：两者成本一样（探针实测 853ns vs 904ns / 27 段），
但限幅只把控制点夹进盒子，**不保证单调** —— 一段真实上升沿仍可能先鼓再落（局部极值）。
波形是给人看强弱走向的，走向不能被插值改掉。PCHIP 的保单调性把这条钉死。

**性能**：四种算法的控制点计算都在 **852~904 ns / 27 段**（JVM，200k 次迭代），差异 < 6%；
绘制成本与算法无关（都是 27 段 `cubicTo`）。真机帧时间见 [`probe-perf-tier.md`](probe-perf-tier.md)。

## 4. 对 v3.2.2 的约束

1. **`Path.cubicTo` 的控制点必须来自 PCHIP 切线**，不得用 Catmull-Rom（铁律 31）。
2. **切线数组必须跨帧复用**（`remember` 的 `FloatArray`），`Path` 也必须复用一个对象
   （`path.reset()` 后重写）—— 每帧 `Path()` 或每帧构造点列表都违反零分配契约。
3. **被插值的量是半厚（振幅域）**，不是柱值：插值保证作用在"像素高"上，
   `h_i ≥ minBar/2 > 0` ⇒ 顶部包络 `centerY − h(x) ≥ 0`，底部包络不会越过中心线。
4. **`x` 控制点固定在 1/3 处**：`Path` 的 x 单调是"横轴仍是时间"的几何表达（任务书 §3.1）。
