# Ncrust v3.2.2-gpl 更新说明（用户可读）

## 波形变了：一条曲线 → **三条频带泳道**

横屏大屏（以及竖屏的全屏波形背景）里的波形以前是 28 根跳动的柱子。现在它**按横轴分成三块**，
每块画的是**那一个频段自己的时间曲线**：

```
 左：低频（鼓 / 贝斯）   中：中频（人声 / 吉他）   右：高频（镲片 / 齿音）
```

- **三块各自滚动**，但**首尾无缝拼接**成一条连续的曲线（接缝处的点距与段内完全一样，
  看起来是一条带子，不是三张图拼起来）；
- **接缝处用渐变色过渡**，每块在自己的区间里是纯色；
- **不把三个频段的差别抹平**：左边的高度只由低频决定、右边只由高频决定，不做跨频段的平均。
  三条曲线还各自做了**显示增益标定**（低 2.6 / 中 3.5 / 高 6.6 —— 高频段的能量本来只有低频段的
  40%，不标定的话右边永远是一条贴着中线的直线），所以鼓点的脉冲、人声的持续、镲片的碎抖
  各看各的形状。

曲线用**单调三次插值（PCHIP）**连接。为什么不直接用最常见的 Catmull-Rom：
在 5 首真实歌曲、19055 帧、825 万个采样点上实测，Catmull-Rom 有 **224 帧会画出"负高度"**
（曲线穿进自己的镜像里，看起来像波形翻了一下），而 PCHIP 的**过冲与负高度都是 0**。

## 三条泳道的颜色

- **低频 = 低音色**（主题色的三色组之一）
- **中频 = 主题色本身**（实测中频占 2/3 的时间，所以画面里最常出现的那条就是主题色）
- **高频 = 高音色**

三个颜色由当前主题色经 **HCT**（Material You 的取色模型）推导：色相两两相隔 120°、
彩度 48、明度与主题色一致 —— 也就是**只换颜色、不换亮度**，所以"哪一段更响"这个读法没被改变。
实测三色之间的感知色差（CAM16-UCS ΔE）最小 **10.1**，而 Material 默认的三种角色色只有 5.1
（36 个真实主题色样本里 0 个达到"一眼能分辨"）。

另外，**哪条泳道在主导，那条会亮一点**（另两条暗到 78%）—— 这个"亮一点"的切换走完整的防闪，
见下节。

## 颜色/亮度**不闪**（这是本版花力气最多的地方）

最朴素的做法（每一帧看哪个频段能量最大就切换）实测切换频率是 **1.258 次/秒**
（电子乐 2.0 次/秒），缓冲粒度更细的设备上是 **4.26 次/秒** —— 那不是"跟着音乐走"，
那是频闪。所以本版做了**三级防闪**，全部有实测数字支撑：

| 机制 | 效果（5 首 1219 秒实测） |
|---|---|
| 三频带各自平滑（时间常数 300ms） | 1.258 → 0.308 次/秒 |
| 滞回：新频段要比当前频段高 **20%** 才算主导 | 0.308 → 0.118 次/秒 |
| 安静段落保持当前主导（静音闸门） | 最短驻留 100ms → **300ms** |
| 切换处 **100ms 过渡**（不是硬切） | 每帧最大色差 17.58 → **7.13** |
| 过渡期间不接受新切换 | "过渡被打断" 128 次 → **0 次** |

最终：**平均 0.103 次/秒、最差曲目 0.169 次/秒、零"闪断"**（一次停留 < 100ms 的次数为 0）。

## 各档位怎么变

| 档位 | 波形 |
|---|---|
| **简洁**（低端机默认） | 三条频带泳道 + 峰值标记 |
| **精致**（默认） | 简洁档全部 + 流光（叠在泳道上的一层移动亮带）+ 柱顶光点 + 呼吸 |
| **炫技** | 精致档全部 + 冲击波 / 粒子 / 3D 透视 + 底部三条频带能量条 |

> **三档都会按频带着色**（这一条是按用户反馈改的：低端机的默认档就是简洁档，
> 按档位收窄的后果是默认体验只有一条单色曲线）。频带着色由设置里的
> 「多频段波形调制」开关管，与档位、与「界面动效」总开关都无关。

- **「界面动效」总开关关掉** ⇒ 波形**完全不受影响**（照旧画曲线、照旧按频带着色）；
  它只管背景呼吸 / 粒子 / 歌词律动那一层。
- **「界面律动」开关**（节拍那一层）**也不影响波形**。

## 没有声音数据的时候

如果解码器不给音频数据（特征链路不可用），波形会**退回一条单色曲线**（v3.2.1 的形态），
而不是把两条没有数据的泳道画成贴着中线的直线 —— "没测到"不许画成"是零"。

## 稳定性

波形是**每帧都在更新**的组件，所以本版给它补了三层异常隔离（音频线程那一段本来就有）：

- 组合期算颜色失败 → 三个频段色合一（等于退回单色），不会崩；
- 绘制一帧失败 → **丢这一帧**，不向上抛、不重试，下一帧照常；失败次数可以在
  `WaveformStore.droppedCurveFrames()` 里查到；
- 音频特征拿不到（解码器不给数据） → **如实退回单色**，而不是把"测不到"画成"全是低频"。

音频线程**一行新增计算都没有**（频段数据本来就是它每缓冲算一次的既有产物）。
本版**没有新增任何设置项**，也没有新增持久化字段。

## 本版没有做 / 没有验证

- **PCL110（Android 16）没测**：本轮那台设备不在线。更细缓冲下的鲁棒性有 23ms 的对照实测支撑，
  但没有该机型的观感与帧时间。
- **主题色本身的对比度**：有 5/36 个组合（例如"素白"主题 + 浅色底）对比度偏低，
  其中素白浅色下**以前那条单色波形同样看不见** —— 这是既有性质，本版没有顺手改。
