# Arris 4.1.13-gpl 发布验收

2026-11-25。Android 10 及以上，versionCode 246，versionName `4.1.13-gpl`。

这是一个**修复版**：`4.1.12` 的搜索页有样式 bug（筛选档浮在第一行结果上），请直接装 4.1.13。

- APK 10,835,308 字节，SHA-256 `202f1d6d503cdbe142d6c5e3aca1620b13d59852bb55c795e39f3615cabd1c4b`。

## 本版唯一改动

`SearchScreen` 里给悬浮下拉指示器当画布的那个 `Box`，里面的兄弟节点（逐源统计行之后的筛选档、
加载行、结果列表）被叠着放了 —— v4.1.12 之前它们是外层 `Column` 的子节点，竖排。
改成 `Box { Column(fillMaxSize) { when (currentType) { … } }; PullToRefreshOverlay(…) }`。

真机验证（PLC110 / Android 17 / ColorOS 16，装 4.1.13 前一版同代码包）：
搜「love」→ `ncm 共 371 首 · qm 共 1044 首 · B站 19 首` 下面单独一行是
`双源 / 只看 ncm / 只看 qm / 只看 B站`，结果从筛选档下方开始，不再重叠。

## 与 4.1.12 的关系

内容完全相同（库页表头收起、单曲搜索与加载更多、艺人页单曲取全、识曲点按即播/长按搜索、
下拉刷新悬浮层、后台复活）。按仓库纪律**已发布的 tag 与制品不原地替换**，所以另起一版。
4.1.12 的 Release 正文已标注「请用 4.1.13」。
