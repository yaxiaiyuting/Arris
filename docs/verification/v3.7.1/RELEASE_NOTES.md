# Arris v3.7.1-gpl（versionCode 87）

- 修复断网缓冲、暂停或后台恢复时歌词可能把等待时间计入播放进度：恢复后重新对齐真实位置，过旧采样最多外推 750ms；迟到的旧曲目取词任务不得重新取得当前请求身份。
- 账号与登录页显示 QQ 音乐 VIP/SVIP、B站大会员到期日期。QQ 保留完整时分秒并按北京时间解析；B站新增日期缓存，旧数据缺失显示未知。资料刷新失败保留缓存，QQ 写回受当前会话版本保护。
- 当前码率除接口值外，支持实际选中音频轨道、完整文件长度与时长补齐，覆盖离线播放等接口未返回码率的路径。预载下一首不覆盖当前歌曲。
- 音频缓存默认从 512 MiB 扩为 1 GiB，新增 12/16 GiB 档位，上限 16 GiB。保留用户明确设置过的容量；设置页和缓存浮层共用候选，容量调整下次启动生效。
- 调整随机播放的艺人分散策略，减少每轮开头偏向同一批艺人；保存与完整队列身份绑定的洗牌顺序和游标，重启后继续未播完的一轮。手动下一首复用轮末已预排的顺序，与无缝预载一致。

未进行真机测试；验证结果见同目录 RELEASE_VERIFICATION.md。会员接口缺少到期字段、音频轨道与文件元数据均不可用时如实显示未知或省略码率，不按请求音质编造数据。
