## 修复清单

| 编号 | 修复内容 | 关键改动 |
|---|---|---|
| S1 | QQ 部分/降级歌单不再被当成"完整同步成功" | `LocalPlaylistRepository.loadRemoteOutcome` 保留 `fresh/degradation`；不完整时写盘但**不更新 `lastSyncedAt`**，返回新的 `LocalSyncOutcome.Partial` |
| S2 | 在途同步不再复活已删歌单 / 覆盖删除标记 | `LocalPlaylistStore` 新增 `revision`（每次落盘/删除 +1）+ `writePlaylistWithTracksIfUnchanged(expectedRevision)`；`sync` 提交前复核修订号与"key 仍存在" |
| S3 | QQ 按账号清缓存匹配错字段 | `clearOwner` 改为按 SEP 切段匹配第 3 段，覆盖 `list/list_at/detail/detail_at` 四种形状 |
| S4 | 统计清空与旧 flush 反写窗口 | `StatsStore` 新增 `commitLock`：代次校验与实际 `commit()` 在同一把锁内；`clear` 的删除也带自己的代次 |
| S5 | 本地歌单写盘失败仍返回成功形状 | `persist` 返回布尔；`addTrack/removeTrack/clear` 失败返回 `null`；MainActivity 与详情页只在成功时提示并关闭对话框 |
| S6 | B 站登录收尾跨会话写入 | `BiliAuthStore` 新增 `loginGeneration`，`finishLogin` 落盘后取代次，`clear`/`saveProfile` 走 `*IfCurrent` |
| S8 | 缓存枚举失败被当成空目录 | 新增 `OfflineAudioCache.keysOrNull`；`reconcileLibrary` 拿不到真相就不裁剪 |
| S12 | 清首页缓存未清新鲜度 | `ContentCache.clearAll` 同时把 `homeWarmedUpAt` 归零 |
| S13 | 空列表快照不覆盖旧值 | `HomeSnapshot.save` 语义定死：`null` = 未提供，空列表 = 成功清空（`remove`） |
| S15 | 队列读写把取消当故障 | `flushPendingQueue`/`getQueue` 重新抛出 `CancellationException`；读失败不再 `clearQueue`；写盘带代次，过期快照提交作废 |
| S16 | 退出播放器清掉播放模式 | `clearState` 只删当前播放状态 key，保留 `play_mode`/队列/续播 |
| S17 | 收藏/取消反序提交 | `pushLike` 按曲目串行（per-key `Mutex`）+ 最新意图覆盖，被覆盖的旧意图不再发 |
| S18 | 异步云端写未绑定原会话 | 排任务时钉住 `NeteaseSessionSnapshot`；`likeSong` 三个通道逐段复核代次，`createPlaylist`/`addSongs` 接受 `pinned`，不符即拒发 |
| S19 | 局域网配对暴露密钥材料 | 协议升到 `NCRUSTPAIR2`：二维码追加 `&arris=<secret>`，请求带 challenge，应答带 HMAC 证明，密钥改为 `SHA256(secret|unikey)`；二维码无 secret 时**拒绝回传**（不静默回退） |
| S20 | 车机重建 QQ 曲目丢取链载荷 | 新增 `recoverPayload(context, source, id)`，按 TrackKey 从本地歌单/收藏补回 `sourceId`/`mediaId`；补不到仍判 `UNRESOLVABLE`，不换源 |
| S21 | 旧收藏身份与音源载荷不一致 | `SavedSongCodec` 解码出口统一 `withPayloadSourceAligned()`，以 `trackKey` 为准回填/纠正 `song.source` |
| S22 | 网易歌单写接口接受跨源 id | `addSongs` 在唯一写出口用 `SourceIds.isNeteaseId` 拦掉 QQ/B 站合成 id |
| F1 | 车机试听时长单位错误 | 新增 `account.trialSeconds(start, end)` 作为唯一换算出口（秒），车机路径不再除以 1000 |
| F2 | 车机忽略移动数据音质偏好 | `currentQualityLevel` 按当前网络在 `KEY_WIFI` / `KEY_MOBILE` 间选择，与手机主路径一致 |
| F3 | 云端加入歌单失败仍弹成功 | `addSongsToPlaylist` 失败时用 `addToPlaylistFailed` 文案，并钉住会话 |
