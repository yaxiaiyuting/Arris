# Arris v3.7.7-gpl

版本：versionCode 93。修复上轮源码审查确认的五类问题。

- 旧重试不再抢回播放权：网络与降档重试保存原曲目的完整载荷和播放代次，等待结束先复核。切歌、同曲重播、换档、暂停和停止撤销旧任务；系统媒体暂停也会通知播放请求层。
- 收藏冷加载不再覆盖旧库：新增、批量新增和删除先在锁内加载旧数据，首次加载与缓存共用真源；快照和落盘串行执行。修复首次专辑写入只改了副本的问题。
- 网易云取链第二次网络异常仍按 NETWORK 分类并进入单调冷却；取消不重放，重试后的业务拒绝保留自身语义。
- 网易云收藏专辑按完整分页读取，失败、缺失数组和停滞页保留旧缓存；确认的空数组仍可正常更新为空，刷新返回实际结果。
- QQ 收藏歌单读取超过 50 条时继续分页。附加读取失败保留旧收藏和已取到的新项，标记降级且不把部分结果缓存为新鲜；未知结构不再冒充空表。

验证：3,100 项 JVM 测试，0 失败；新增 26 项定向回归。独立无窗口 API 33 模拟器的 8 项本地静音播放服务检查通过，涵盖跨源身份、旧请求/预载拦截和系统切歌。未做真机测试或真实账号联网验证。

附件包含 release/debug APK、mapping、SHA256SUMS 和本说明。本版本保持 GitHub 草稿，供用户测试。
