# Arris v3.7.4-gpl（versionCode 90）

修复 v3.7.3 使用中反馈的跨源身份与切歌问题，保留 v3.7.3 的五类审查修复、网易云续期和 QQ 歌单鉴权续期。

- 从 QQ 切到网易云时，播放服务完整替换音源身份并清掉旧 songmid / media_mid，网易云默认空 source 不再沿用 QQ 身份；新媒体项、通知与歌词使用一致身份。
- 手动下一首、上一首与自然曲终分开。单曲循环只在自然结束时重播当前项，手动导航可切到其他曲目。系统媒体命令在播放器执行层处理，避免授权回调与 Media3 默认行为重复执行；内部只有一首媒体项时也可导航应用队列。
- 新播放请求取消旧取链和预载；IO 返回后的主线程提交与 Service 接收 Intent 时分别校验播放代次。预载同时校验队列代次与所属当前歌曲，避免把下一首挂到仍未切走的上一首后面。
- 网易云主动续期在后台按需进行，不阻塞本可播放的新歌请求；明确收到鉴权拒绝后才等待刷新并最多重试一次。

- 补齐旧缓存迁移边界：旧完整曲标签缺少文件验证代次时按未知处理；在线取得完整曲后，仅为仍含未验证旧字节的 key 使用独立缓存项，避免旧试听字节冒充完整曲。旧缓存保留可离线回退。

- 局域网凭证交接增加严格 UTF-8 和会话结构校验，拒绝错误密钥偶尔通过填充检查后得到的无效文本。

新增纯逻辑回归与后台模拟器的本地静音播放探针，覆盖跨源身份清理、旧预载/旧播放 Intent、手动下一首和系统 MediaController 导航。本轮不做真机安装或播放测试，未向真实账号发送续期或上报请求。正式包不包含调试探针或静音素材。
