## 一、会话归属与写入顺序（续 3.7.8 的 S17/S18）

- **收藏意图按「账号 + 曲目 + 序号」隔离**：旧账号的 worker 发现会话过期时，只能**条件删除**
  「自己领取的那一条」，不再抹掉新账号刚写的意图；同账号续期不再被当成换号（R1）。
- **专辑 sub/unsub 与单曲同构**：按 albumId 串行 + 最新意图覆盖 + 钉住登录代次（H01）。
- **专辑刷新不再覆盖读取期间的编辑**：`albumEditRevision` 在锁内复核，旧快照直接丢弃（R2）。
- **歌单所有写出口在进门控之前取会话快照**，门控释放后按登录代次复核：换号即作废、续期照发（H02）。
- **播放上报钉住快照**：上报产生时捕获 cookie + 登录代次，后台线程比对代次，变了直接丢弃（H03）。

## 二、数据与缓存

- **部分同步不再虚报成功**：`Partial` 只有真的落盘成功才返回，写盘失败 / 修订冲突 / 期间删除一律 `Failed`（R3）。
- **新建本地歌单可判失败**：`createLocalOnly`/`createPlaylist` 失败返回 null，界面保留对话框并提示（H09）。
- **远程读取区分「失败 / 不完整」**：`RemoteRead.{Complete,Incomplete,Failed}` + `LocalPartialCause`（H10）。
- **载荷回查跳过不可解析记录**（H11）。
- **QQ 歌单完整性由「声明总数 vs 实收数」判定**，不完整结果不覆盖已知完整缓存（H21）。
- **缓存枚举/操作失败不再裁剪或清空离线索引**（E01，续 S8）。
- **统计：清空与落盘共用代次 + 单调票号**（J01）；**统计快照读取也持写入锁**（H19）。
- **下载：尝试序号与「每目标最新尝试」进程级**，跨实例也成立（H04）。

## 三、播放器 / 队列 / 桌面卡片

- **暂停中 seek 会刷新卡片**：位置判据对播放/暂停一视同仁，空闲重复仍被压掉（R4）。
- **续播位置越界即撤销**：按本曲真实时长核对，回退到起点区间也撤销（H16）。
- **在播身份与「是否换歌」解耦**：`next == current` 时也落定身份（J07）。
- **队列拖拽提交按身份重定位 + `finally` 收尾**（E10）；**行 key / 隐藏 / 悬浮全走含来源的身份**（E11）。
- **播放意图代次闸门**：主页异步开播（私人 FM / 歌单 / 专辑）返回时若已被新动作取代就丢弃（K01）。
- **启动恢复队列不再覆盖用户刚建的队列**（K02）。
- **长寿命触摸协程读最新几何**（K04）；**单泳道接入滚动相位**（K06）；**波形点数上限 64→96**（J13）；
  **拖拽速度按屏幕 Y 约定反号**（J12）；**版本档位迁移不覆盖新键**（J14）；**试听标记透传到小屏与大屏音质控件**（K09）。

## 四、跨源 / B站 / 字幕

- **候选专辑的艺人证据只来自候选自己**，并引入三值 `ArtistVerdict`（H05）。
- **QQ 主源的聚合不再漏网易侧**：两侧各自按 source 分派取数（H06）。
- **B站 AV 与 AU 身份分区**（AV 用位 60 标记，AU 原样兼容）（H14）。
- **B站凭据按域白名单**：只有 `*.bilibili.com` 带 Cookie/Referer，字幕 CDN 与第三方一律匿名（H17）。
- **字幕时间戳支持 100 分钟以上**：`LrcParser` 两处正则放开到多位分钟（H18）。
- **B站扫码取消态不被在途响应覆盖**（E08）；**QQ 扫描连接隔离旧回调**（H20）。
- **QQ 新老字段成组兼容**（J10）；**副文本对齐按最近主轨 + 完全匹配优先**（E02）；
  **网易艺人页封面不再拼成腾讯模板**（E03）。

## 五、其它

- **首页缓存绑定账号归属**：写入前复核，换号整份丢弃（H15，续 S14）。
- **配对回传加完整性**：TCP 载荷 = 密文 ‖ HMAC-SHA256(secret, unikey‖密文)（H23）。
- **红心歌单身份以 `specialType==5` 为准**，名字只在特殊歌单里兜底（H24）。
- **导航参数不再二次解码**（H08）；**首次设备标识在进程内串行**（H07）；**登录凭据接受度三态判定**（J02）。
- **下拉刷新松手归零**（J16）；**后台权限返回后刷新白名单**（K08）；**QQ 验证码仅换值也能识别**（E04）。
- **列表入场动画被重排移出范围后收敛到终态**（J17）；**清空搜索撤销在途提交权**（J09）。
- **试听时长单位统一**：`trialSeconds` 只在 `account` 里定义一份（J05 同源修正：PCM 交错样本换算除以声道数）。
