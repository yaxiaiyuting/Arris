Arris **4.0.5-gpl** 主线测试包 · Android 10 及以上 · versionCode **205**。

- **播放页改版**：新的 Tux 启动图标和播放按钮，封面、歌词、进度和控制键共用一层背景。
- **卡拉 OK 跟唱**：在展开的播放器打开歌词，点击右上角的跟唱图标。当前句大字显示，有逐字时间戳时随播放扫亮，只有 LRC 时整行高亮；下一句提前显示，前奏和明确有时间边界的长间奏会给入唱提示。有译文时可切换主行，保持播放、切歌和跳转能力。
- **背景呼吸**：到「设置 → 外观与动效」选择精致或炫技档，打开背景呼吸。低频改变封面色光范围，中高频轻推亮度；暂停和缓冲时收回静态。Android 13 及以上可试「流体背景」，省电或渲染条件不足时回退为渐变。
