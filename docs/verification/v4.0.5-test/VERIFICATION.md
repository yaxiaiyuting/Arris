## 4.0.5 测试中发现的回归（已在 4.0.6 修复）

- **竖屏控制栏未收起时歌词比例不对**：歌词被挤在上半屏、下方空出一条；收起控制栏反而正常。
  根因是 4.0.2 给歌词面板加的底部留白（`waveBackdropHeightDp × 0.75`），它从歌词视口扣高度，
  而「当前行落在视口 36%」是相对视口的锚点 ⇒ 锚点在屏幕上整体上移。
- 修法：面板占满可用高度（可视条是背景层，不需要为它让位）。
- 真机验证：展开态当前行落在视口 36%（此前约 17%）；收起态无回归。
- 同一修法已同步到 LTS 3.7.28。
