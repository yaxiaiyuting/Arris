# 4.0.5 跟唱与背景 · 隔离冒烟检查

- 基线：含本轮功能的 Debug 包；采集截图之后又上调了跟唱当前句的未唱文字对比度，最终版本由独立签名构建校验。
- Android API 33，隔离无窗口模拟器，飞行模式，Wi-Fi 和蜂窝均关。只预填项目自产 MP3、合成封面和歌词，不使用真实账号或网络取流。
- 竖屏从歌词工具栏进入跟唱，保留标题和歌手，确认两行语言切换，使用实际缓存播放后看到词内亮度推进。暂停后歌词高亮停在当前时间，系统返回回到普通歌词。
- 1920×900 横屏大屏模式进入跟唱，返回键回到大屏播放器。记录了原文主行、译文主行及横屏的截图。
- 临时 Android Instrumentation 在该 API 上实例化 app 的流体着色器，确认 AGSL 能编译。低端设备帧耗时、GPU 行为和功耗仍需真机验证。
