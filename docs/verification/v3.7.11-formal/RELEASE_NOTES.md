# Arris 3.7.11-gpl 正式整合版

显示版本为用户指定 **3.7.11-gpl**，内部 **versionCode99**，高于此前3.7.12-gpl双语测试包98。测试包、标签和历史验证材料保留。本轮仅生成本地正式包，没有推送代码或上传GitHub。

## 已整合的功能

- 双语系统媒体歌词：默认原文上、译文下，允许译文作为主行；无翻译、空翻译或重复翻译回退单行。播放面板、锁屏通知和Live Updates共用同步帧。
- 单语歌词恢复歌名/歌手信息；双语的额外歌曲信息放在通知SubText和会话description，实际额外行是否显示由Android/ROM决定。
- 保存原工作区31文件快照的全部更新，包含歌词手动选段、长海报/Tux、分享路径、首页预热和数据边界改进；保留现有生日动画与交互。

## 核心修复

- 收藏与歌单：迁移后合并同一曲目身份，保留手动收藏和删除意图；删除/转存写盘失败正确回滚；QQ翻页钉住整批会话；网易写操作将账号/CSRF一直钉到传输，多步创建/加歌保持同一归属。
- 播放和队列：用户点击时领取播放意图，撤销旧联网开播任务并在提交前核对；Infinity不能把旧结果追加到新队列。清空队列不被旧flush复活；重复歌曲拖拽按队列实例快照，列表已变则放弃；删除在播项立即接续下一项，删除后为空则停止。
- 搜索与页面：失败页先重试，不跳页；HTTP成功但业务码失败不再冒充空结果。网易歌单列表读取后续页，游标含隐藏特殊歌单原始条数；QQ歌单重登按钮接通登录入口。
- 会话和生命周期：临时校验失败只短退避，成功才消费长TTL；首页磁盘恢复与共享预热绑定会话；旧扫码响应不污染新会话；ViewModel解绑完整且不能清掉新owner的回调。
- 图片与缓存：当前/预载封面和取色统一按代次在Main提交，无封面清理旧状态；背景导入使用独立临时文件和最新意图提交门，清除可撤销旧导入。缓存失败不再显示成功提示；临时分享图与永久保存海报分目录。
- 入口边界：B站自动重定向逐跳去除域外凭据，含秘密的POST不跨账号域转发。保留公开Media3服务，内部start命令使用进程能力值；桌面卡片走私有Receiver，冷服务时打开应用、恢复队列后重新取链续播。

## 已知限制与明确未改项

- **无真机/模拟器验证**。本轮不打开可见浏览器、不播放视频或音频；设备布局、Android生命周期/桌面宿主及系统额外歌词行的最终视觉效果未验收。JVM结果不能替代这些验收。
- 用户反馈U01（封面偶发遮挡歌名/小球）明确要求当前仅记录，因此没有调整尺寸。
- 本地歌单中有明确bv载荷的旧B站视频可归一并合并重复。旧离线曲目表和歌词缓存仅有裸ID，缺少AV/AU证据，无法安全判断同号属于视频还是音频；保留这些缓存，不猜测改号或删除文件，新身份可能重新取词/缓存。不能声称所有历史缓存已无损迁移。
- 未带真实qq_songid的更早QQ散列身份仍不能反推原数字ID；不编造迁移信息。
- 重定向回归只构造本地请求并检查实际拦截器，未向外域发送凭据，也不声称真实平台已发生泄露。
