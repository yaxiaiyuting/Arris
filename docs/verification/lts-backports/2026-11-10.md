## Android 7.0 验收

- 在 API 24 上用原 3.7.35 签名包复现只缓存榜单却显示离线空态。新源码的普通 Debug 构建通过了只有榜单缓存和完全无缓存两种路径。
- 扫码用临时 Debug 构建把两个传输地址指向回环 HTTP 和 WebSocket，其余界面、MQTT 编解码、凭证解析和落盘走生产逻辑。Android 飞行模式开启，按 App UID 阻断非回环 IPv4 和 IPv6 出站。测试使用虚构二维码和凭证。
- 刷新后只有新二维码对应的连接存活。凭证请求在途时按返回键，连接关闭，延迟响应未写入 cookie。
- 在同一进程内用 Android 7 的「不保留活动」销毁并重建 `MainActivity`。原二维码仍显示「已扫码，请在手机上确认」。再次销毁 Activity 后确认，cookie 和续期凭证在后台落盘。返回账号页可见登录态，整个过程只有一次换凭证请求。Android 7 的测试开关使用 ActivityManager 事务 43。 [Android 7 源码](https://github.com/aosp-mirror/platform_frameworks_base/blob/android-7.0.0_r1/core/java/android/app/IActivityManager.java#L735)
