## 一、搜索：从「只有 30 条」到「翻到底自动续」

### 你报的是对的，而且比表面看到的更严重

搜索结果**只有一页**：`cloudsearch` 的 `offset` 恒为 0（接口本来就是分页的，
代码里从来没传过第二个页），界面上也没有任何「还有更多」的出口 ——
你既看不到被截断了、也没办法取下一页。

现在三个 tab（**单曲 / 专辑 / 艺人**）都能翻页，而且是**滚到最底部自动加载**：
你当时说「不要用点击，滚到最底部自动触发就行」—— 对，翻页是「列表到底」这个动作的
自然延续，让你为此再点一次是把「浏览」切成了「浏览 + 操作」。

底部只会显示一行「正在加载…」，其余时候什么都不画。

## 二、顶部统计改成**总曲库数**（你的建议，原话照做）

> 「最顶部哪个音源多少个歌曲也没有实时更新，建议用抓取的总曲库数字作为哪个音源多少首的度值」

你说的确实是个真缺陷：那一行此前显示的是「**这一轮取回了多少条**」，
而这个数字**不随翻页变化** —— 所以「ncm 30 首」既读起来像「ncm 只有 30 首」，
翻页后也确实纹丝不动。

现在显示的是服务端声明的总数，实测数据：

| 关键词 | ncm | qm |
|---|---|---|
| 周杰伦 | 273 首 | 999 首 |
| 青花瓷 | **300 首** | **993 首** |

界面上是 `ncm 共 300 首 · qm 共 993 首`。服务端偶尔不给总数时**如实回落**成
「已载 N 首」（而且那个 N 是**累计**已加载，不是本页 —— 否则翻页前后都显示 30，
又是一次「看起来没实时更新」）。

这一行现在**三个 tab 常驻**（你要的「统一的整体在搜索栏下方」），
切到专辑/艺人 tab 也看得到。

## 三、专辑：按「名字 + 歌手」匹配，优先原唱

> 「专辑界面也做和单曲界面类似的搜索处理，优先原唱，原歌手，用搜索的歌手名字匹配专辑作者」

查下来这件事此前**在结构上做不到**，有三个缺口：

1. **专辑的歌手信息从来没有被用来定位专辑** —— `AlbumKey` 里那个 `artistKey` 字段一直存在，
   但没有任何一处代码写过它，于是匹配逻辑里「锚点的歌手」恒为空字符串；
2. 去另一个平台**只按专辑名搜**，而且只看前 3 个候选 ——
   同名专辑（原版 / 精选 / 现场 / 翻唱合集）的正主排在第 4 位以后就等于没配上，
   而界面还会显示一个「已匹配」的置信度，你没有任何线索知道配错了；
3. 直取专辑元信息失败时（下架 / 换 id）**没有兜底**，而名字一旦拿不到，
   连给另一平台构造搜索关键词都做不到 ⇒ 那一页**永远只有一个音源**。

现在：搜索用「**专辑名 + 歌手名**」召回；候选按「名称必须相同（硬门槛）+
歌手相同优先 + 合作艺人（`A / B` vs `A`）次之 + 曲目数相同再加一分」排序；
**同名但歌手对不上**的候选直接跳过。这三条抽成了一个纯函数模块并配了 11 条单测，
逐条覆盖了合作艺人、翻唱合集、精选版多两首这些真实形状。

## 四、艺人页与专辑页补上下拉刷新

> 「音乐作者界面里的单曲和专辑仍然没有下滑刷新」

对，两页都缺。现在两页都能下拉刷新（复用的是仓库里既有的下拉组件，
与搜索页/歌单详情页同一套手势判据）—— 刷新 = 重新走一遍聚合。

## 六、这次是怎么验的（你让我自己测）

我起了一台 API 33 的模拟器（qemu，无头）在上面跑：

| 验的东西 | 结果 |
|---|---|
| 应用启动 | 无崩溃，进程存活 |
| 搜索两源 | `netease=30 qq=30` 双双到手 |
| **滚到底自动翻页** | 日志 `滚到底 ⇒ 自动加载下一页` → 2.3 秒后第二页到手；继续滑累计触发 3 次（第 2/3/4 页） |
| 列表内容确实是新的一页 | 截图确认屏上是《青花瓷（戏腔版）》《青花瓷 钢琴》这些**不在第一页**的条目 |
| 顶部统计 | 截图确认 `ncm 共 300 首 · qm 共 993 首` |
| 崩溃 | 全程无 |

**这次也踩到了一个真 bug 并且是靠实测抓到的**：我第一版的「滚到底自动加载」
**根本不会触发** —— 因为判据写在了 `LaunchedEffect` 里，而滚动列表**不会改变
它的任何一个 key**，所以那段代码只在首屏渲染后跑过一次。日志铁证：连续滑 12 次，
`lastVisible` 一直是 6（首屏那一屏）。改成观察滚动状态本身（`snapshotFlow`）之后才真的生效。

这一条如果没有模拟器实测，就会像上一版那三个 bug 一样**发到你手上才被发现**。
所以你这句「测试功能完好后自行发布即可」我照做了。
