开始之前，你可能想知道。

需要分别登录网易云和 QQ 音乐吗？

是的，两个音源使用各自的账号和登录态。会员专享、高音质、付费曲目等权限仍由对应平台判断。

识曲和一起听在所有版本都能用吗？

这些功能在 3.8.x 功能线中持续开发，旧版本不一定提供。请查看对应 Release 的更新说明；识曲需要麦克风权限及网易云登录态，一起听需要双方可用的连接方式和曲目权限。

下载很慢，或者老是断？
本站直链走 Cloudflare，国内速度取决于线路。可以先试 主站直链（支持断点续传）；仍然慢的话用 GitHub Releases。安装前可按发布页的 SHA-256 校验安装包。
主线和 LTS 有什么区别？

主线面向 Android 10 及以上，承载新功能与体验更新。3.7.x LTS 兼容 Android 7 起，主要维护错误修复与稳定性。不同系统上的可见功能和系统媒体面板样式可能不同，请以所装版本的发布说明为准。

离线缓存等于下载了完整歌曲吗？

播放过一部分，不代表整首已缓存。只有完整缓存的音频才能在离线列表直接回放；缓存会受容量上限和清理操作影响。音乐权限仍由对应音源决定。

怎样开启双语歌词或发现 Tux 彩蛋？

在歌词设置中调整翻译、音译和主行偏好；没有翻译时会回退单行。系统通知和实况窗的最终可见行数取决于系统模板。生日可以在应用中设置，关于页连续点击版本号 7 次还有一个小彩蛋。

想反馈问题，或者参与开发？

欢迎到 GitHub Issues 描述复现步骤、应用版本和设备信息。源码、构建配置与许可证都保留在仓库中。

中继接口与自行构建说明
本站同时提供一起听中继，仅转发房间状态，不转发音频。接口如下：
GET /health — 健康检查GET /rooms — 活跃房间目录WS /room/<房间码>?role=host|member&name=昵称
客户端与中继构建方法见 项目源码及 README。签名 Release 需要配置 keystore.properties。
